# Projet les Fourcasters

Formation : Data Analyst à la wild code school / Simplon

Equipe : Angélique THEVENET, Christophe LAW-YUN-KAI, Eddy HEROUT, Loïck MARTIN

## Contexte

Ce projet GitHub a pour but de créer un modèle de pipeline automatique partant de la récupération de certaines données publiques jusqu'à la mise en place de tableau de board qui s'actualisent et de machine learning prédictive.

La problématique centrale est de quantifier l'augmentation des risques (inondations, canicules, incendies) sur la société française et prédire la probabilité future de ces risques avec l'évolution du climat.
